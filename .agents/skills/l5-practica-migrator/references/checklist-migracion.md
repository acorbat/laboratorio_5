# Checklist de migración (L5)

## Criterios obligatorios

- [ ] Se buscó material en `materials/` antes de redactar.
- [ ] Si hay guía, se usó como fuente principal y prioritaria.
- [ ] El texto migrado no tiene formato de receta/instrucciones imperativas para estudiantes.
- [ ] Se describe fenómeno + contexto + interés experimental.
- [ ] Se incluyen objetivos de aprendizaje.
- [ ] Se incluyen preguntas orientadoras.
- [ ] Se incluyen links de seguridad pertinentes.
- [ ] Se cita fuente original (guía + manifest).
- [ ] Si se usó marker-pdf, se revisó manualmente sintaxis/formato del markdown resultante.
- [ ] Ecuaciones y bloques matemáticos verificados/corregidos manualmente.
- [ ] Imágenes movidas a `experimentos/assets/<slug>/` y enlaces actualizados.
- [ ] Temporales eliminados al finalizar (o justificado uso de `--keep-temp`).
- [ ] Si la extracción fue incompleta, quedó aclarado como migración parcial.

## Criterios de calidad recomendados

- [ ] Consistencia de tono con el resto del sitio.
- [ ] Terminología física correcta.
- [ ] Links funcionales.
- [ ] Estructura de secciones completa.
